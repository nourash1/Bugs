# Bugs
Bug 1: Incorrect Total Price Calculation

During checkout on academybugs.com, the shipping fee is displayed as $21, but the final total incorrectly increases to $125. This inconsistency indicates a calculation or pricing logic error in the checkout system. The bug affects the accuracy of pricing and could lead to customers being overcharged.

Bug 2: Screen Freezes When Changing Currency

When switching the currency using the website’s currency selector, the screen freezes and becomes unresponsive. This issue prevents users from navigating or completing transactions after the currency change. The bug appears to be caused by a JavaScript/UI refresh failure, affecting usability and navigation flow.
![software3](https://github.com/user-attachments/assets/8ee0e76b-7b7e-4891-ba25-894895e1940b)

Bug 3: Sign In Button Text Misaligned Vertically

On the Sign In page, the caption inside the “Sign In” button is not vertically centered. This is a user interface alignment issue that makes the button look unprofessional and poorly designed. While it does not affect functionality, it impacts the visual quality and user experience of the login interface.
